MONSTER RUSH: SURVIVAL — FULL-SCREEN GAMEPLAY UPDATE

Upload index.html, style.css, and game.js to the root of your GitHub repository, replacing the old versions, then commit the changes.

Play in landscape. Tap START SURVIVAL to begin. The game has a movement joystick, automatic shooting, enemies, coins, health, and wave progression. There is NO pause button.

Browser fullscreen and landscape locking depend on browser/device support. For a more reliable app-like fullscreen experience without browser UI, package it as an Android app later using Capacitor.

Prototype only: PHP/MySQL accounts, persistent server saves, energy, ads, and weapon unlock shop are not included yet.
